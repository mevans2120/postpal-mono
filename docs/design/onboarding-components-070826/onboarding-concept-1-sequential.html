Why this composition

Lens: Stacked / Sequential + Space-Forward. This is the most literal extension of the Daybook's core rule — the "calm budget," one ask above the fold. Each screen holds a single Petrona statement and one primary action, exactly like the check-in state. The progress dots (clay pill for the current step) are the only new primitive, and they reassure an anxious pre-procedure patient that setup is short and bounded.

Strengths: lowest cognitive load, trivially matches the existing state machine (one more phase enum: onboard, stepping 0→4 before checkin), and reuses .eyebrow, .bigtext, .factline, .marginnote, .btn unchanged. Tradeoff: five taps to finish; the honest-expectations beat gets one screen rather than room to breathe.

Tokens used — surface: --paper / --card · text: --ink, --mut · accent: --clay (hero em, active dot), --clay-deep (margin note, fact emphasis), --clay-fill (primary button, 4.75:1 white) · calm: --pine (hand-off button) · structure: --line hairlines · type: Petrona 24.5 hero + 15 body, Albert Sans 11/700 eyebrow & labels
